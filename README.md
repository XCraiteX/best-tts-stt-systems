> Я очень долгое время занимался разработкой различных голосовых асистентов и всегда стоял вопрос распознавания и синтеза речи. Писал на синтезаторах silero-tts, pyttsx. ## 1. Speech-To-Text

Для преобразования речи в текст (распознавания) я рекомендую использовать Faster-Whisper. Быстрое локальное распознавание чанков с микрофона.

**Плюсы:** Очень хорошее качество распознавания и поддержка нескольких языков <br>
**Минусы:** Пока не нашёл.

**Зависимости:**

```bash
pip install realtimestt[faster-whisper]
pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu121
```

**Параметры:**

Можно поменять `compute_type`, отличия в таблице:

| Значение       | Скорость      | Память     | Качество          |
| -------------- | ------------- | ---------- | ----------------- |
| "float32"      | Медленно      | Много      | Лучшее            |
| "float16"      | Быстро        | Средне     | Почти лучшее      |
| "int8_float16" | Очень быстро  | Мало       | Примерно такое-же |
| "int8"         | Быстро на CPU | Очень мало | Чуть ниже         |

## 2. Text-To-Speech

Для преобразования текста в речь (синтеза) я рекомендую использовать `edge-tts`. Речь синтезируеися через Microsoft Edge TTS, код получает MP3 по частям и воспроизводит через Pygame.

**Минусы:** нужен интернет, есть задержка генерации.
**Плюсы:** хороший голос, относительно быстрый синтез, легко настроить.

**Зависимости:**

```bash
pip install edge-tts pygame
```

## 3. TTS -> RVC

Ещё один вариант. По скорости года медленнее edge-tts, но позволяет воспроизводить голос голосовыми моделями из `.path` и `.index`.

**Зависимости:**

1. FFMPEG

```bash
winget install -e --id Gyan.FFmpeg
```

2. Зависимости

```bash
pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu121
pip install tts-with-rvc
```
